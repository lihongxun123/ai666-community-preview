页面定位投稿弹层承接活动详情 CTA，用户在这里完成标题、提示词、适用场景、推荐模型和可选案例素材。
用户主路径用户从 campaign-prompt.html 打开投稿弹层，补齐必填字段，点击单个发布按钮；发布成功后进入 AIGC 灵感广场并自动打开对应 Prompt 详情弹层。
关键字段必须展示标题、提示词、适用场景、推荐模型和效果图/视频；弹层头部只保留发布 Prompt 标题，不再叠加活动名。适用场景使用最多 3 个标签的多选控件，推荐模型使用下拉选择，字段解释和校验规则不直接占用 C 端编辑区。
状态规则标题、正文、场景和模型未达标时主按钮置灰；纯文字达标显示一键同款加 20 积分，图文/视频达标显示一键同款加 40 积分，每日上限只显示感谢共创。
动作去向发布动作进入 aigc.html#prompt-detail-media；返回活动进入 campaign-prompt.html；效果图/视频任务可通过 prompt-submit.html#prompt-media-upload 定位到上传区。
运营维护维护校验提示、每日上限提示和入选奖励文案时，需要同步活动详情页、AIGC Prompt 详情弹层和积分中心，避免入口页与投稿页奖励不一致。
字段校验规则标题必填，trim 后 4-40 个字；超出时显示计数警告，不自动截断，未达标主按钮禁用提示词必填，中文正文 30-2000 字，英文或中英混合不少于 20 个英文单词；只允许纯文本和换行，不保留富文本样式适用场景至少选择 1 个、最多选择 3 个标签；达到 3 个后未选标签禁用，取消已选标签后恢复可选，标签文案不使用斜杠分割推荐模型必选，使用模型下拉项，不支持自由输入；模型为空或被移除时主按钮禁用并提示重新选择效果图/视频为可选案例素材，允许 JPG、PNG、WebP、MP4、MOV；最多 3 个媒资，单个图片建议不超过 10MB，单个视频建议不超过 100MB；不符合类型或数量时停留在上传区并提示原因主按钮只有一个：纯文字达标显示一键同款、积分图标和 20；存在图片或视频案例且字段达标显示一键同款、积分图标和 40；积分图标统一使用 Finance/coins-line.svg；达到每日前 2 条奖励上限后仍可提交，但积分文案改为感谢共创已上传媒资右上角必须提供删除按钮；删除后重新计算媒资数量和积分文案；点击缩略图进入图片或视频预览弹层，关闭预览回到上传区提交成功后按媒资状态进入 aigc.html#prompt-detail-text 或 aigc.html#prompt-detail-media；失败或未达标时保留用户输入、选中标签、模型和已上传媒资，不清空表单
研发验收页面必须包含 data-prompt-submit-modal、data-prompt-submit-field、data-prompt-validation-rule、data-prompt-scene-multiselect、data-prompt-scene-option、data-prompt-model-select、data-prompt-upload-dropzone、data-prompt-upload-thumb、data-prompt-upload-remove、data-prompt-media-preview、data-prompt-submit-remix-cost 和单个 data-prompt-submit-publish；适用场景默认选中 3 个标签且上限为 3，标签文案不包含斜杠；弹层头部只保留一个发布 Prompt 标题且高度控制在 58px 内；如弹窗内容需要内部滚动，标题栏保持吸顶，底部主操作栏保持吸底且初始可见；适用场景和推荐模型拆为上下两行；提示词输入区使用紧凑高度；主按钮文案按媒资状态显示一键同款、积分图标和积分数量，积分图标统一使用 Finance/coins-line.svg，成功目标必须指向 AIGC Prompt 详情弹层，页面不展示投稿状态与奖励预览右侧面板，弹层底部距离视口底部至少 24px。
