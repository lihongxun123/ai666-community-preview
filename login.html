运营关注研发关注
页面定位`login.html` 是全局 `loginPanel` 的静态走查状态，不作为真实 C 端独立路由；普通登录、游客注册引导、未登录点击活动/积分/邀请/消息和带 invite 参数进入都打开同一弹层。
用户主路径手机号与 6 位验证码完成登录；未注册手机号验证后自动注册并登录，邀请码可选并可由 URL 的 invite 参数带入。微信扫码获取二维码后按 scene_id 轮询状态。
关键字段手机号 phone、6 位验证码 code、可选 invite_code；二维码 qrcode_url、scene_id、expire_time；轮询状态 state、remark。任何 token 都不得出现在原型和走查证据中。
状态规则二维码状态 0 为未扫码、1 为成功、2 为过期；只有 state=1 时接口返回 token。手机号无效时不发送验证码，验证码不足 6 位时不提交；登录失败保留手机号和邀请码、清空验证码。
动作去向登录成功回到触发登录前页面；注册成功同时完成“首次访问多元拾光”，自动登录后先展示 +20 积分 Toast，再由活动中心气泡提示“浏览AIGC作品”。未登录点击受限活动、积分、邀请和消息只打开登录弹层，不提前进入目标页面。
运营维护登录弹层不承接活动奖励、积分赠送或营销规则；协议文案由正式协议页维护，二维码过期和接口失败提示使用服务端 remark 的用户可读内容。
接口依据`GET /api/user/login/get_wechat_qrcode`、`GET /api/user/login/get_wechat_qrcode_state`、`POST /api/user/login/send_code_for_login`、`POST /api/user/login/login_by_phone`。
研发规则phone 必须通过大陆手机号校验；code 按 Apifox 当前契约固定为 6 位，不再写成 4-6 位或建议值invite_code 仅为可选字段，Apifox 当前没有 6-12 位大写字母或数字约束，原型不得自行增加该规则扫码轮询只显示未扫码、成功、过期和 remark；token、scene_id 等内部值不直接展示给用户或写入证据验证码发送需要客户端 IP 频率限制；原型 60 秒倒计时只表达前端防重复点击，不替代服务端限制登录成功后由用户 store 更新身份、积分和通知数据，并关闭全局弹层；失败时保留 phone 与 invite_code，清空 code
研发验收页面主内容只保留一个全局登录弹层状态；手机号、验证码、可选邀请码、发送验证码、登录、微信二维码、扫码状态、关闭和协议入口完整；手机号和验证码校验、invite 参数带入、发送倒计时和错误提示可走查；`horizontalOverflow = 0`。
交付边界静态原型不发送真实短信、不轮询真实微信会话、不保存认证凭证、不建立真实登录态；所有成功反馈均为本地走查状态。
