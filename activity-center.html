运营关注研发关注
页面定位活动中心承接用户主动找活动的固定入口；首页、闪念、AIGC、消息和限时积分中心中的活动位继续作为导流入口。
用户主路径用户从顶部特殊入口进入活动中心，平铺查看当前活动，进入对应活动详情或业务承接页；结束活动只能查看回顾。
关键字段活动卡片展示活动名称、状态值、单行 C 端描述、时间值、奖励或回顾摘要和目标入口；状态固定在卡片左上角，时间放在描述下方，参与动作和完整奖励规则由活动详情、隐藏结构和走查规则承接，不进入卡片主内容。
状态规则活动状态包括进行中、奖励待确认、已完成和已结束；历史活动不展示继续参与动作。
动作去向生图挑战进入活动详情，Prompt 共创进入活动说明页，新手与七日进入对应任务详情页，邀请有礼进入邀请页；当前活动卡片不直接跳功能页。
运营维护活动中心维护活动排序、状态、时间、入口、奖励摘要、卡片短描述和回顾内容；当前活动卡片描述只写用户能理解的一句话，不写沉淀、回流、路径或配置类表达；限时积分中心只维护限时积分资产、赚限时积分入口和限时积分记录。
研发规则当前活动卡片必须包含活动名称、状态、单行描述、时间、奖励摘要和查看详情 href；标题建议 4-24 字，描述建议 8-32 字，奖励摘要只显示最高可得或核心奖励状态值固定为进行中、奖励待确认、已完成、已结束；进行中卡片按钮为查看详情，已结束卡片按钮为查看回顾，不展示继续参与动作当前活动按 3 列平铺，不设置主推大卡；少于 3 个时保持同一网格节奏，多于 6 个时按运营排序分页或进入更多活动，不在首屏堆长列表跳转目标固定：AI 生图进入 campaign-detail.html，Prompt 共创进入 campaign-prompt.html，新手任务进入 campaign-new-user.html，七日成长进入 campaign-seven-day.html，邀请有礼进入 invite.html往期活动复用同一活动卡片结构，只读展示状态、时间、回顾摘要和查看回顾；不使用字段表，不在活动中心展示限时积分记录或个人任务进度活动中心只做活动入口聚合；完整规则、投稿要求、限时积分上限和邀请限制必须进入对应承接页，不倾倒到活动中心主内容
研发验收顶部活动中心必须是 header actions 内的特殊胶囊入口，不进入普通主导航；活动中心不再展示独立 Hero 卡片，当前活动作为首屏主体直接出现；当前活动按 3 列松弛卡片平铺，不设置主推卡，标题行不放限时积分记录旁路入口；活动卡片不展示参与动作，描述必须是单行 C 端短句；进行中任务奖励只显示最高可得限时积分，已结束活动只展示本期历史奖励摘要；往期活动必须复用同一张活动卡片结构，不使用中部字段表；进行中按钮为查看详情，已结束按钮为查看回顾；主内容不得展示标题标签、字段配置说明或运营配置口径。
