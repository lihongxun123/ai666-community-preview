状态规则Banner 只展示接口已启用数据并按 sort 升序；链接按 link_type 在当前页或新窗口打开。爆款作品首屏 page=1、page_size=20，筛选固定为全部、图片生成、视频生成、文本内容、短剧漫剧，值分别为 all、2、3、4、1；切换筛选回到第一页，滚动追加直到达到 total。无 Banner、无作品广告和无作品时分别进入对应空状态，不使用本地数据兜底伪装接口成功。
动作去向首页负责分发。普通轻创作结果可以继续做成漫剧或发布闪念；选择 AI 生图创作挑战后，结果态额外提供发布活动作品并回到 campaign-detail.html#campaign-submissions。生成按钮同时展示动作和当前模型限时积分。作品卡只进入详情或当前状态，Prompt 卡进入 Prompt 详情弹窗；固定入口承接漫剧、模型、镜像站和轻创作，内容流广告卡进入活动、创作、AI商城或限时积分页。
运营维护首页 Banner 来自 `/api/banners/list`，爆款作品来自 `/api/works/hot`，作品广告来自 `/api/works/meta/ads`。四个固定入口由当前 C 端代码维护；镜像站为外部入口，点击前显示离站确认。当前原型快照只用于表达字段和状态，不是长期运营数据源。
研发规则固定入口保留 4 个并按真实代码排序：漫剧制作、一句话生成、模型体验季、镜像站；一句话生成打开 AIGC 生成面板，模型体验季进入模型广场，外部入口先显示离站确认Banner 响应按 Apifox 当前 data 数组读取，不依赖契约中不存在的 enabled、link_url 或说明字段；代码兼容 data.list 和 link_url 的行为只登记为兼容差异爆款作品请求 page_size=20；content_type 值固定为 1-漫剧、2-图片、3-视频、4-文本，全部不传 content_type；普通作品卡只进入详情，不在卡片上放互动按钮作品广告只有接口返回非空列表时占据瀑布流固定区域，按 sort_order 升序；internal 使用站内路由，external 显示离站确认任务轻引导只消费活动中心现有任务结果，不建立第二套结算配置；优先级固定为游客注册、下一项新手任务、当天已解锁七日任务、活动中心其他积分任务，同一时刻只出现一层游客首次进入时由活动中心锚点气泡引导注册；显示游客注册任务时，顶部账户同步为“积分 -- / 登录”，不得与登录态积分和头像并存；注册或任务完成后先展示实际奖励 Toast，随后重新选择下一项可执行任务并展开活动中心气泡；新手任务全部完成后切换到当天七日任务奖励 Toast 使用无关闭按钮的紧凑样式，只展示奖励结果和完成对象，约 2.6 秒后自动消失；奖励结果未知时使用“任务已完成，奖励结果请稍后查看”，不得提前写已到账；下一任务由后续活动中心气泡承接，不在 Toast 内放进度或操作按钮当天七日任务完成且下一天尚未解锁时，仍有其他积分任务才展开气泡并引导活动中心；没有其他可执行任务时，完成 Toast 消失后结束，不再展开气泡。次日再展示新解锁任务。游客注册、新手任务或当天七日任务未完成时，页面刷新后继续展示当前任务气泡；关闭只结束当前页面提示。#quick-create、#quick-create-campaign、作品详情和发布弹层打开时均抑制任务提示，任务数据不可用时不自动弹出轻创作入口与生成面板沿用真实首页已有 ModInspirationBar 和 ModAigcGenerate 交互；生成所需模型、积分和输入合同在 C-02C 单独对齐

研发验收固定入口需包含漫剧制作、一句话生成、模型体验季和镜像站四张卡。底部轻创作入口只做轻量唤起，桌面宽度不超过 340px，移动端按视口收窄，并使用软圆角而非满圆胶囊；该入口加载后只做一次轻浮现，斜向扫光由悬停或键盘聚焦触发；点击时胶囊需以底部入口为锚点向上连续形变为轻创作弹层，不强制居中打开；关闭时回收到胶囊，并需尊重减少动态效果偏好。爆款作品不少于 50 张，首位有宽幅轮播广告，中部穿插卡片式广告位，普通内容卡不得展示点赞、评论、收藏或分享动作位；Prompt 筛选需指向 #case-gallery-prompt，Prompt 卡片需进入 Prompt 详情弹窗；作品详情弹层固定按漫剧、图片、视频、文本、Prompt 五类承接，左侧随格式展示单视频、图片变体、Markdown 预览、无媒资 Prompt 内容或带媒资 Prompt 的图片/视频，普通内容右侧统一为标题、标签、提示词/评论 Tab、底部点赞收藏分享与一键同款，评论区使用全局评论组件类名；无媒资 Prompt 详情右侧为标题、标签、模型信息/评论 Tab、底部点赞收藏分享与一键同款；带媒资 Prompt 详情右侧为标题、标签、提示词/评论 Tab、底部点赞收藏分享与一键同款。普通作品不展示右侧简介段落；Prompt 详情不使用旧摘要字段散落布局；详情弹层不展示生成扣次模块、复制状态说明、媒资标签或分类标签。轻创作弹层输入态不展示标题栏和关闭图标，关闭由遮罩承接；生成中、结果和分发态在最外层弹层右侧显示外置关闭按钮，点击后关闭弹层并回收到轻发布入口；三模式 Tab 使用紧凑图标加文字表达，并减少外层分割线；输入态外层容器不再保留边框，实际内容宽度等于原外框宽度；输入态需支持三个模式点击切换、textarea 输入、图片模式上传包裹在输入区内且按钮按内容宽度收拢、按模式显示模型池、图片/视频比例、模型限时积分和主动生成按钮，按钮内限时积分图标需位于数字之前；长模型列表需要可滚动且可点击，模型名完整展示，选中态与限时积分分列不重叠，点击模型选项后下拉自动收起，模式切换时弹层高度保持稳定。点击生成后需使用 GSAP 从输入态扩展到更宽更高的生成中态，生成中进入专属处理场景并隐藏顶部内容类型框体；对话区展示用户输入气泡、AI 处理说明、带进度提示的小尺寸生成预览和底部输入灵感输入区，当前模型放在底部输入区内并跟随生成前选择；点击小预览进入结果态大图预览。生成中、结果和分发阶段仍锁定为发起生成时的类型，返回调整后恢复输入态类型切换且保留原输入内容；结果态和分发态保持与生成中态一致的大框体尺寸，结果态左侧为大结果预览且徽标为 AI 生成，右侧按结果详情侧栏组织，顶部只展示当前结果类型一个标题并与下载、分享、收藏操作对齐，生成说明保持单行不中断；中部先展示基础参数，再用提示词卡片承接剩余高度，提示词复制使用无边框图标按钮；底部不展示额外说明标题，继续调整以独立次级按钮承接，两个下一步动作平铺展示；继续调整返回生成中对话状态，分发态保留继续做成漫剧和发布闪念两个目标，并尊重减少动态效果偏好。站内链接需落到正式页面集合，页面不保留 href=# 空链或 floating-deal。
